---
title: "agentx"
description: "Inventory the agent clients, skills, MCP servers and plugins on your machine from one command line."
---

`agentx` is a command line tool. Run it from a terminal or script it with `--json`.

## Build from source

```sh
cd apps/cli && go build -o agentx .
```

## Commands

- [`agentx scan`](/cli/scan): list every agent configuration on this machine and the skills each one sees.
- [`agentx source`](/cli/source): add the git repositories you install skills from, fetch them again, list their skills, and remove them.
- [`agentx skill`](/cli/skill): install skills into your library, one at a time or a whole source at once, place them in your agent clients, see and revert your changes to them, repair their placements, remove them again, and list what you have.
- [`agentx adopt`](/cli/adopt): take over the skills the vercel skills CLI installed, without reinstalling them.
- [`agentx version`](/cli/version): print the CLI version and its output schema version.
- [`agentx doctor`](/cli/doctor): check that this machine can run agentx.
- [`agentx config`](/cli/config): list, get and set this machine's settings.
- [`agentx machine`](/cli/machine): show this machine's id and label, rename it or reset the id.
- [`agentx export` and `agentx import`](/cli/export): copy this machine's settings to another machine, with a list of the skills to bring back.
- [`agentx serve`](/cli/serve): keep watching this machine and stream a snapshot whenever it changes.

See [Output and exit codes](/cli/output) for `--json`, logs and what each exit code means.
