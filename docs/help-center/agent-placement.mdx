---
title: "Choose symlink or copy for an agent"
description: "Choose on the Agents page of the desktop app whether an agent gets each new skill as a symlink to your shared library or as its own copy."
---

agentx keeps your skills in one shared library, `~/.agents/skills`. It places each skill in every agent client that does not read the library directly, as a symlink to the library by default. Choose a copy instead for an agent client that does not follow symlinks.

This page uses the terms library and placement. See the [glossary](https://github.com/grundmanise/agentx/blob/main/GLOSSARY.md).

## Choose symlink or copy

1. Open **Agents**.
2. On the agent's card, under **Placement**, select **Symlink** or **Copy**.

The control shows your choice once agentx has saved it. Hover the control to see what each choice means.

## What each choice means

| Choice | What the agent gets | Use it for |
| --- | --- | --- |
| **Symlink** (default) | A link to the skill in your library. The agent reads the library, so an update or an edit shows at once. | Most agent clients. |
| **Copy** | Its own copy of the skill. agentx refreshes the copy when you update the skill, and keeps a copy you edited. | An agent client that does not follow symlinks. |

The agents on the **Universal** card read the library directly, so they have no choice to make.

## What changes

The choice applies to the skills agentx places in that agent from now on: when you add, create or fork a skill, or place a skill there. Skills already in the agent keep how they were placed until you convert them.

## Convert the skills already in an agent

1. Select **Symlink** or **Copy** on the agent's card.
2. In the message that confirms the change, select **Convert existing**.

agentx turns each skill already in the agent into the kind you chose. It keeps a copy you edited in place as a copy, so your edits stay, and says how many it kept. To discard those edits, open the skill, turn the agent off under **Agents**, then turn it on again.

## From the command line

`agentx config placement` does the same:

```sh
agentx config placement kiro-cli copy
```

Add `--convert` to also convert the skills already in the agent:

```sh
agentx config placement kiro-cli copy --convert
```

See [`agentx config`](/cli/config).
