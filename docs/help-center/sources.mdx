---
title: "Sources in the app"
description: "Browse the sources you added, add skills from them or from a link, and refresh or remove a source in the desktop app."
---

A source is a git repository that holds skills. In the desktop app, open **Skills**, then **Sources** under it, to see every source you added and add skills from them.

This page uses the terms source, account remote and library. See the [glossary](https://github.com/grundmanise/agentx/blob/main/GLOSSARY.md).

## Browse a source

Each source has a pill at the top of the page, with the number of skills it holds. **Personal** lists your own skills on your account remote that this machine does not have yet. An amber dot marks a source that was not fetched in the last two days, or never.

Select a pill to open the source. Its card shows:

- Its name.
- Its full URL under the name, with the [pin](/cli/source#pin-a-source) it follows after `#`. Select it to open the repository in your browser.
- **Read-only** when you cannot write to it.
- **Skills**, **Branch**, **Commit** and **Fetched**: how many skills it holds, the branch it follows, the commit of its last fetch and when that was.

Under the card, the source's skills are listed one per row, with a line of each skill's description.

To look in every source at once, type in **Search all sources**. The card hides while you search.

## Read a skill before you add it

Select a skill's row to open it. The row shows a spinner while it reads the skill's `SKILL.md`, then opens to show it. Select **View skill**, next to the skill's name, to open the skill's folder in its repository in your browser. Select the row again to close it. You can keep several open.

For a skill you cannot add, the open row says why. A skill under **Personal** shows its description only.

## Add skills

1. Select the round check at the end of each skill you want, or select the **Select all** checkbox above them, at the right, to select every skill you do not have yet. Select it again once all are selected to clear the selection.
2. In the bar at the bottom, choose the agents to add them to. Universal agents, marked with a lock, always get them.
3. Select **Add**.

Skills this machine already has show their status in place of the check, such as **Added**, and you cannot select them. Skills stay in A to Z order when you add them.

## Remove an added skill

1. Hover over **Added** at the end of the skill's row. It changes to **Remove**.
2. Select **Remove**. A dialog lists every agent that sees the skill.
3. Select **Remove** to delete the skill from universal agents and every other agent on this machine, or **Cancel** to keep it.

To get the skill back, add it again from its source.

## Add skills from a link

1. In **Skills**, select **Add**.
2. Paste a link to a repository, a folder of skills or one skill on GitHub or GitLab, such as `https://github.com/anthropics/skills/tree/main/skills`. A skill's folder or its `SKILL.md` works too, and for GitHub, `owner/name` or `owner/name/path`.
3. Select **Find skills**, or press Enter. agentx lists the skills under the link.
4. Select the skills you want. A single skill is selected for you. Skills this machine already has are marked, and you cannot select them.
5. Under **Add to**, choose the agents to install them in. The enabled agents are chosen to start with. Universal agents, marked with a lock, always get the skills.
6. Select **Install**.

agentx adds the source to **Sources** only when you install a skill from it. Select **Cancel** to close the dialog without changing anything. Once the skills are installed, the first one is selected in the list.

## Add a source

1. Select **Add source**.
2. Paste the repository's URL, or `owner/name` for GitHub. Add `#branch` or `#tag` to pin it.
3. Select **Add**.

The new source opens with every skill selected.

## Refresh a source

On the source's card, select **Refresh**. agentx fetches the source again and lists its skills from the new fetch.

## Remove a source

1. On the source's card, select **Remove**.
2. To remove the skills you installed from it as well, select the option that also removes them. It lists them by name, and shows only when this machine has skills from the source.
3. Select **Remove**.

Without that option, the skills you installed from the source stay in your library and in your agents. There is no undo: add the source again to get it back.

Your account remote has no **Remove** here. Change or detach it in **Settings**. See [Account remote](/account-remote).

## From the command line

[`agentx source`](/cli/source) adds, fetches, lists and removes sources, and [`agentx skill`](/cli/skill) installs and removes skills.
