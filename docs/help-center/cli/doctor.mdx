---
title: "agentx doctor"
description: "Check that this machine can run agentx: git, agentx home and the account repo."
---

Run `agentx doctor` before your first install, or whenever something looks wrong. It only reads: it never creates or changes anything in agentx home.

```sh
agentx doctor
```

```text
System
  ✓ git                      ok    git 2.43.0
  ✓ merge_tree               ok    merge-tree --write-tree --merge-base merges two branches
  • relative_worktree_paths  info  not available: git 2.43.0 is older than 2.48
  ✓ isolated_commit          ok    commit 5d75017e77f5413f4337ef776244b8d8dc77ca90
  ✓ home                     ok    not created yet: /home/me/.agentx; the first scan creates it

App
  ✓ lock                     ok    free: /home/me/.agentx/lock
  ✓ mutations                ok    none unfinished: /home/me/.agentx/mutations
  ✓ settings                 ok    defaults: /home/me/.agentx/settings.json is not written yet
  ✓ account_repo             ok    not created yet: /home/me/.agentx/account.git
  ! library                  warn  missing: /home/me/.agents/skills

Clients
  • client:claude-code       info  Claude Code: /home/me/.claude
  • client:cursor            info  Cursor: /home/me/.cursor
  • clients                  info  2 of 75 registered clients detected

  ! library  missing: /home/me/.agents/skills
             hint: create it with mkdir -p /home/me/.agents/skills
```

When every row is `ok` or `info`, the report ends with `✓ No issues detected` instead.

The rows are grouped by what they check: `System` is git and the home directory, `App` is agentx's own state, `Clients` is every detected agent configuration and their count. In a terminal the rows are coloured by status: green for `ok`, yellow for `warn`, red for `fail`, blue for `info`. Read the last block first: it repeats every warning and failure with its fix.

## What it checks

| Check | Meaning |
|---|---|
| `git` | git is in `PATH` and at least 2.40. |
| `merge_tree` | git can merge with `merge-tree --write-tree`, which updates need. |
| `relative_worktree_paths` | Whether git is 2.48 or newer. Informational. |
| `isolated_commit` | agentx commits produce the same id on this machine as on every other, whatever your git configuration. |
| `home` | agentx home is writable, or does not exist yet. The first scan creates it. |
| `lock` | No other agentx command holds the lock. When one does, the detail names its process id. |
| `mutations` | No change to agentx home was cut short by a crash. When one was, the detail names its journal; run `agentx scan` to finish it. If that refuses because the file changed meanwhile, restore the file or move the journal aside. Doctor only reports. |
| `settings` | `settings.json` parses. |
| `account_repo` | The account repo opens, or does not exist yet. |
| `library` | The library directory exists. A missing library is a warning, not a failure. |
| `client:<id>` | One row per detected agent configuration, naming the client and its configuration directory. |
| `clients` | How many of the clients agentx knows are detected. A warning when none is: install an agent client, or check that `HOME` points at the right user. |

Each row is `ok`, `warn`, `fail` or `info`, marked `✓`, `!`, `✗` or `•`. Every `warn` and `fail` row is listed again at the end under `<n> issues`, with its fix as a `hint:` line under the detail.

## Exit codes

- `2`: git is missing or older than 2.40. The hint names the fix; on Ubuntu 22.04, which ships git 2.34, install a newer git or upgrade the distribution. Every other command except `version` refuses to run until git is fixed.
- `8`: `account.git` in agentx home exists but is not a repository git can read. Check the directory, or move it aside.
- `0`: everything else, warnings included.

## Script it

Add `--json` to get one `doctor` event per check with `check`, `status`, `detail` and, when there is a fix, `hint`:

```sh
agentx --json doctor
```

```json
{"type":"doctor","schema_version":1,"check":"git","status":"ok","detail":"git 2.43.0"}
{"type":"doctor","schema_version":1,"check":"library","status":"warn","detail":"missing: /home/me/.agents/skills","hint":"create it with mkdir -p /home/me/.agents/skills"}
{"type":"result","schema_version":1,"ok":true}
```

Add `--verbose` to see every git command doctor ran and what git printed.
