---
title: "agentx version"
description: "Print the CLI version and its output schema version."
---

Run `agentx version` to see which build you have.

```sh
agentx version
```

```text
CLI version     dev
Schema version  1
```

The CLI version is one of:

- A release version, such as `0.2.0`.
- A nightly version, such as `0.3.0-nightly.20261001`. It is the next release version, followed by the build date.
- `dev`, for a build from source.

The schema version is the version of the [`--json` output](/cli/output#json-output). The agentx desktop app reads this output.
