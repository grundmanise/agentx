---
title: "agentx version"
description: "Print the CLI version and its output schema version."
---

Run `agentx version` to see which build you have.

```sh
agentx version
```

```text
CLI version     dev
Schema version  1
```

A release prints its version, such as `0.2.0`, and a nightly build prints the version it leads up to and its date, such as `0.3.0-nightly.20261001`. `dev` means a build from source. The schema version is the version of the `--json` output the desktop app reads.
