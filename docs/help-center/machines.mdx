The **Machines** screen of the desktop app shows the skills of each of your machines: this machine, every other machine that reports to your hub, and the cloud machine. You can read a machine's skills while that machine is off.

This page uses the terms hub, inventory report, library and cloud machine. See the [glossary](https://github.com/grundmanise/agentx/blob/main/GLOSSARY.md).

## Before you start

Set a [hub](/hub#add-it) on each machine. Without a hub, **Machines** lists this machine alone. Select **Open Settings** there to add one.

## Let a machine report

A machine shows on your other machines once it writes its inventory report to your hub.

1. On that machine, open **Settings**.
2. Under **This machine**, turn on **Report inventory**.

While the switch is on and the desktop app is open, agentx writes the machine's report to your hub on its own:

- **After a change**: about a minute after the machine's skills last changed. Several changes in a row make one report.
- **When the app starts**: after about a minute, if the report on your hub is not the one of this machine as it is now.

The first report follows about a minute after you turn the switch on. The switch is off by default, and you turn it on machine by machine. Without a hub, you cannot turn it on.

The switch is the machine setting `report_inventory`. See [Let agentx write the report](/cli/machine#let-agentx-write-the-report).

On a machine without the desktop app, or to write the report now, run [`agentx machine report`](/cli/machine#write-this-machine’s-report).

The report holds the names of the machine's skills and plugins, their versions and their sources. It holds no path, no machine setting and no file of any skill. Anyone who can read your hub can read the report. For everything it holds, see [Write this machine's report](/cli/machine#write-this-machine’s-report).

## See the machines

Open **Machines**. The list shows:

1. This machine, as it is now.
2. Your other machines that wrote a report, by label.
3. The [cloud machine](/cloud), from its snapshot.

Each row shows the machine's label, its agents, when its report last changed on the hub, and how many skills its agents see. A skill that several agents see counts once. The date is not when the machine was last on.

agentx reads your hub each time you open the screen. While the app is open, it also checks your hub every 10 minutes and updates the list when a report changed.

## See a machine's skills

Select a machine. The right side shows its machine id and, for another machine, its operating system, its agentx version and when its report last changed.

Under them, each agent of the machine lists the skills it sees, and where each skill comes from:

| Value | What it means |
|---|---|
| **Library** | A skill in that machine's library, followed by its source. **Hub** means a hub skill. **Modified** means the skill was edited on that machine. |
| **`<name>` plugin** | A skill that the plugin `<name>` brings. |
| **Skills directory** | A skill in the agent client's own skills directory that agentx does not manage. |

**Disabled** beside an agent's name means the agent is disabled on that machine. Select the name to collapse or expand its skills.

For the cloud machine, the skills are what each cloud agent session is given. To change them, see [Change the cloud machine's skills](/cloud#change-the-cloud-machine’s-skills).

## Take a machine off the list

To take a machine off the list, open **Settings** on that machine and select **Unlink** under **Hub**: unlinking the hub deletes the machine's report from it. Turning **Report inventory** off keeps the last report, so the machine stays in the list.

## From the command line

`agentx machine list` and `agentx machine show` do the same. See [See the skills of your other machines](/cli/machine#see-the-skills-of-your-other-machines).
