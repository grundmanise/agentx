---
title: "Clean up leftover agents"
description: "Remove the configurations of agent clients you do not use from the Agents page of the desktop app."
---

A tool that installs skills into every agent client it knows, such as the Vercel skills CLI or Skillshare, creates a configuration directory for each client. agentx then lists each one on the Agents page, including clients you never installed. Remove these leftover configurations to keep only the agents you use.

This page uses the terms configuration, library and placement. See the [glossary](https://github.com/grundmanise/agentx/blob/main/GLOSSARY.md).

## What can be removed

agentx removes a configuration only when you lose nothing. Its directory may hold:

- Links to skills.
- Copies of skills that your library or another agent also holds, with the same content.
- Empty directories.

A configuration that holds anything else stays: a skill that is only there, MCP server declarations, plugins, settings or history.

Removing a configuration deletes its directory. Your library and your skills stay as they are.

## Remove many at once

1. Open **Agents**.
2. Select **Clean up**. The button shows when at least one configuration can be removed.
3. Check the list. Each row shows the directory that is deleted. Untick the ones you want to keep.
4. Select **Remove**.

The cards disappear from the Agents page.

## Remove one

1. Open **Agents**.
2. On the agent's card, open the **⋯** menu and select **Remove**.
3. Check the directory in the dialog, then select **Remove**.

For an agent that cannot be removed, the dialog lists what its directory still holds. Move or delete those files yourself if you no longer need them, then try again.

## From the command line

`agentx config remove` does the same. See [Remove a leftover configuration](/cli/config#remove-a-leftover-configuration).
